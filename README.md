# Asus-WebSite_Demo

## 🎯 Projenin Amacı
Bu proje, popüler teknoloji markası Asus'un kurumsal kimliğine uygun, statik bir web sitesi demosu oluşturmak amacıyla geliştirilmiştir. Kullanıcı arayüzü tasarımı ve modern web standartlarına odaklanan bu çalışma, temel web teknolojilerinin bir araya getirilerek nasıl responsive (duyarlı) ve estetik bir arayüz sunulabileceğini göstermektedir.

Proje, özellikle yeni başlayanlar için Bootstrap framework'ünün CSS ile uyumlu kullanımına dair pratik bir örnek teşkil eder.

## 🛠️ Kullanılan Teknolojiler
*   **HTML5:** Web içeriğinin iskelet yapısını oluşturmak için.
*   **CSS3:** Görsel düzenlemeler, stil tanımlamaları ve layout yönetimi için.
*   **Bootstrap:** Hızlı, responsive ve mobil uyumlu bir arayüz tasarımı sağlamak için.
*   **Git/GitHub:** Versiyon kontrolü ve kaynak kodu yönetimi için.

# Asus-WebSite_Demo

## 🎯 Project Purpose
This project was developed to create a static website demo suitable for the corporate identity of the popular technology brand, Asus. Focusing on user interface design and modern web standards, this project demonstrates how to present a responsive and aesthetic interface by combining fundamental web technologies.

The project serves as a practical example for beginners, specifically regarding the integration of the Bootstrap framework with CSS.

## 🛠️ Technologies Used
*   **HTML5:** Used for the structural skeleton of the web content.
*   **CSS3:** Used for visual styling, layout management, and design customization.
*   **Bootstrap:** Used to ensure a fast, responsive, and mobile-friendly interface design.
*   **Git/GitHub:** Used for version control and source code management.

## 🚀 Installation and Usage
Follow these steps to run the project on your local machine:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/your-username/Asus-WebSite_Demo.git
   ```

2. **Navigate to the Directory:**
   ```bash
   cd Asus-WebSite_Demo
   ```

3. **Running the Project:**
   Since this is a static project, there is no need for a server setup. Simply open the `index.html` file located in the `Proje_Odev` folder using any modern web browser (Chrome, Firefox, Edge) by dragging and dropping or selecting "Open with."
